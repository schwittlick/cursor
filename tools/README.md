# tools

This directory contains various tools and utilities for the Cursor project.

[**hpgl_visualizer.py**](./hpgl_visualizer.py): Visualizes HPGL files using OpenGL.

Usage:

This tool provides a visual representation of HPGL (Hewlett-Packard Graphics Language) files.
It uses OpenGL to render the plotter commands, allowing you to preview the output of HPGL files without needing a
physical plotter.

Features:

- Renders HPGL commands in real-time

[**mscoco.py**](./mscoco.py): Processes MS COCO dataset

Features

- Renders one segmentation outline at a time, by category
