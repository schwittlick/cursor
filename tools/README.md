# tools

This directory contains various tools and utilities for the Cursor project.

2. [**hpgl_visualizer.py**](./hpgl_visualizer.py): Visualizes HPGL files using OpenGL.

Usage:

This tool provides a visual representation of HPGL (Hewlett-Packard Graphics Language) files. It uses OpenGL to render the plotter commands, allowing you to preview the output of HPGL files without needing a physical plotter.

Features:
- Renders HPGL commands in real-time
- Supports pan and zoom functionality
- Displays different pen colors

Controls:
- Left mouse button: Pan the view
- Mouse wheel: Zoom in/out
- Space bar: Pause/Resume rendering
- Esc: Exit the visualizer
